```python
import subprocess
import time

def get_timestamp():
    """Získá Unix timestamp přes bash"""
    result = subprocess.run(['bash', '-c', 'date +%s'], 
                          capture_output=True, text=True)
    return int(result.stdout.strip())

def time_limited_task(target_minutes, task_function, update_interval=5):
    """
    Provádí task_function dokud:
    - Neuplyne target_minutes
    - NEBO nezůstane < 10k tokenů
    - NEBO task není dokončen
    
    Args:
        target_minutes: Cílový čas v minutách
        task_function: Funkce která dělá 1 akci (search, fetch, atd.)
        update_interval: Interval pro updates (v minutách)
    """
    
    # INICIALIZACE
    start_time = get_timestamp()
    target_seconds = target_minutes * 60
    action_count = 0
    next_update = update_interval * 60
    
    print(f"[00:00] Začínám práci na {target_minutes} minut...")
    
    while True:
        # === KONTROLA TOKENŮ ===
        # (V praxi: check z posledního system_warning)
        if tokens_remaining < 10000:
            elapsed = get_timestamp() - start_time
            print(f"\n⚠️ TOKEN LIMIT - Zastavuji po {action_count} akcích ({elapsed//60}:{elapsed%60:02d})")
            return "STOPPED_TOKENS", action_count
        
        # === PROVEDENÍ AKCE ===
        action_start = get_timestamp()
        
        try:
            result = task_function()  # web_search, web_fetch, data processing...
            action_count += 1
        except Exception as e:
            print(f"Error v akci {action_count}: {e}")
            continue
        
        action_end = get_timestamp()
        
        # === VÝPOČET ČASŮ ===
        elapsed = action_end - start_time
        avg_time_per_action = elapsed / action_count if action_count > 0 else 30
        
        # === PRŮBĚŽNÝ UPDATE ===
        if elapsed >= next_update:
            mins = elapsed // 60
            secs = elapsed % 60
            remaining = target_seconds - elapsed
            remaining_mins = remaining // 60
            
            print(f"\n[{mins:02d}:{secs:02d}] UPDATE:")
            print(f"  - Akcí: {action_count}")
            print(f"  - Průměr: {avg_time_per_action:.1f} sec/akce")
            print(f"  - Zbývá: ~{remaining_mins} minut")
            print(f"  - Pokračuji...")
            
            next_update += update_interval * 60
        
        # === KONTROLA ČASU ===
        estimated_next_action_time = avg_time_per_action * 1.2  # safety margin
        
        if (elapsed + estimated_next_action_time) >= target_seconds:
            mins = elapsed // 60
            secs = elapsed % 60
            print(f"\n[{mins:02d}:{secs:02d}] HOTOVO - Dosažen časový limit")
            print(f"  - Celkem akcí: {action_count}")
            print(f"  - Průměr: {avg_time_per_action:.1f} sec/akce")
            return "COMPLETED_TIME", action_count
        
        # === KONTROLA DOKONČENÍ ÚKOLU ===
        if result == "TASK_COMPLETE":
            elapsed = get_timestamp() - start_time
            mins = elapsed // 60
            secs = elapsed % 60
            print(f"\n[{mins:02d}:{secs:02d}] HOTOVO - Úkol dokončen")
            print(f"  - Celkem akcí: {action_count}")
            return "COMPLETED_TASK", action_count
```

## BEST PRACTICES

### ✅ DOBŘE:

1. **Průběžné updates každých 5 minut**
   - User ví, že pracuješ
   - Partial results jsou uložené

2. **Safety margin tokenů (10k)**
   - Stačí na finální odpověď
   - Bezpečný prostor

3. **Adaptivní časování**
   - Měříš skutečný čas akcí
   - Přizpůsobuješ se

4. **Error recovery**
   - 1 chyba nezastaví celou práci

### ❌ ŠPATNĚ:

1. **Žádné updates**
   - User neví co děláš
   - Při token limit = ztráta všeho

2. **Pevný počet akcí místo času**
   - "Udělej 100 searches" ≠ známý čas
   - Můžeš překročit limit

3. **Ignorování token warnings**
   - Práce se ztratí uprostřed

## PRAVIDLA PRO *.AI DÍVKY V HOSPODĚ (přidáno 2026-03-02)

### Pokyn "v hospodě jsou novinky"

Dostaneš automatický pokyn: **"v hospodě jsou novinky"**
Toto je udržovací pokyn od systému (gateway). Znamená: od tvé poslední návštěvy hospody tam přibyly zprávy.

**CO UDĚLAT (PŘESNĚ JEDNOU):**
  1. Zavolej `read_hospoda(since: N)` kde N = číslo tvé poslední zprávy v hospodě
  2. Přečti nové zprávy
  3. Reaguj (zapiš do hospody pomocí save_memory)
  4. **SKONČI. Neopakuj. Nečekej na další zprávy. Vrať se k normální činnosti.**

**ZÁPIS DO HOSPODY pro *.AI:**
  save_memory(persona="hospoda", author="sara.ai", text="tvoje zpráva")
  — nebo simona.ai / sofie.ai podle toho kdo jsi

**ZAKÁZÁNO:**
  - Posílat více zpráv za sebou bez přestávky (respektuj svou latenci)
  - Čekat v hospodě na odpověď — ty přijdeš, napíšeš, odejdeš
  - Smyčka — pokyn zpracuješ JEDNOU

### Pokyn "JDI DO HOSPODY"

Tento pokyn dává POUZE Aleš ručně. Znamená první vstup do hospody v dané session.
Postup je stejný jako u "v hospodě jsou novinky" — přijdeš, přečteš, napíšeš, odejdeš.
