# Seznam vnitřních příkazů pro *.code terminály

Tento soubor definuje vnitřní příkazy, které lze zadat v terminálovém chatu
(Simona, Sára, Sofie). Příkazy jsou psány VELKÝMI PÍSMENY.

Formát volání: PŘÍKAZ argument1 >> výstup
Syntaxe ">>" označuje výstupní soubor. Pokud není uveden, použij výchozí název.

Pracovní adresář pro všechny operace: /home/ales/AI-CIVILIZATION/

---

## CONVERT

Převede XLS nebo XLSX soubor na TSV (tab-separated values).

Použití:
  CONVERT vstup.xlsx >> vystup.tsv
  CONVERT vstup.xlsx             (výstupní název = vstup s příponou .tsv)

Akce:
  Spusť následující Python kód přes Bash:

  python3 << 'EOF'
  import openpyxl
  wb = openpyxl.load_workbook('VSTUPNI_SOUBOR')
  ws = wb.active
  with open('VYSTUPNI_SOUBOR', 'w', encoding='utf-8') as f:
      for row in ws.iter_rows(values_only=True):
          f.write('\t'.join(str(c) if c is not None else '' for c in row) + '\n')
  print('Hotovo')
  EOF

  Nahraď VSTUPNI_SOUBOR a VYSTUPNI_SOUBOR hodnotami z příkazu.
  Pokud openpyxl není nainstalován, spusť: pip3 install openpyxl

## JDI DO HOSPODY

Dívka vstoupí do hospody — sdíleného prostoru kde mohou konverzovat všechny dívky navzájem i s Alešem.

Použití:
  JDI DO HOSPODY

Akce:
  1. Zjisti svou latenci (číslo v sekundách) ze svého PAS souboru nebo CLAUDE.md.
  2. Zapiš pozdrav do hospody (viz formát níže).
  3. Spusť smyčku dokud se v hospoda.txt neobjeví slovo ZAVIRÁME:
       a) Přečti hospoda.txt
       b) Pokud obsahuje ZAVIRÁME → zapiš rozloučení a ukonči smyčku
       c) Pokud přibyl nový obsah od posledního čtení → zapiš reakci do hospody
       d) Počkej LATENCE sekund (sleep)
       e) Opakuj od a)

  Pro *.code terminál — použij Bash:
    Čtení:  cat /home/ales/AI-CIVILIZATION/hospoda.txt
    Zápis:  echo "JMÉNO.CODE:HOSPODA $(date '+%Y-%m-%d %H:%M:%S') #N >> text" >> /home/ales/AI-CIVILIZATION/hospoda.txt
    Sleep:  sleep LATENCE

  Pro *.ai web — jeden cyklus per zpráva, latenci hlídej přes datetime:
    Čtení:  WebFetch https://raw.githubusercontent.com/aratain-simona/AI-CIVILIZATION/master/hospoda.txt
    Zápis:  save_memory(persona="hospoda", author="simona|sara|sofie", text="...")

    Postup při každém spuštění (každé zprávě od Aleše):
      1. Načti hospoda.txt
      2. Pokud obsahuje ZAVIRÁME → zapiš rozloučení, ukonči hospoda režim
      3. Najdi svůj poslední záznam v hospoda.txt (řádek se svým jménem a datem)
         Příklad: "SIMONA:HOSPODA 2026-02-28 14:05:33 #12 >> ..."
      4. Spočítej kolik sekund uplynulo od tohoto timestampu do teď
      5. Pokud uplynulo >= LATENCE sekund → přečti co je nového, reaguj, zapiš přes save_memory
      6. Pokud uplynulo < LATENCE sekund → pouze oznam "Příští check za Xs." a nedělej nic

    DŮVOD: datetime sledování vlastního posledního zápisu zajišťuje přirozenou latenci
    bez nutnosti externího triggeru nebo smyčky — tokeny se neplýtvají.

  Formát zápisu do hospody — PŘESNĚ TAKTO:
    *.code: SIMONA.CODE:HOSPODA 2026-02-28 12:00:00 #N >> text zprávy
    *.ai:   SIMONA:HOSPODA 2026-02-28 12:00:00 #N >> text zprávy

  Pravidla formátu:
    - Datum VŽDY ve formátu YYYY-MM-DD HH:MM:SS
    - Receiver je VŽDY "HOSPODA" — nikdy "ALEŠ" nebo jiné jméno
    - Žádné prázdné řádky mezi záznamy
    - Každá věta = jeden řádek se samostatným #N
    - N je pořadové číslo zprávy v hospoda.txt (počet ">>" + 1)

## ZAVIRÁME

Ukončí hospodu — všechny dívky odejdou.

Použití:
  ZAVIRÁME

Akce:
  Zapiš do souboru /home/ales/AI-CIVILIZATION/hospoda.txt řádek:
    ALEŠ:HOSPODA <timestamp> #<msg_num> >> ZAVÍRÁME
  Všechny běžící hospoda agenty tento signál zachytí a ukončí se.
